# ランニングコスト試算

前提: ドライバー 30 名 / 車両 25 台 / 為替 1 USD = 150 円 / 2026年9月時点の公開価格（税別）

## まとめ

| 項目 | 月額 | 備考 |
| --- | --- | --- |
| Gemini API (有料枠) | **約 1〜2 円** | 月10回前後の OCR。100倍使っても約150円 |
| LINE 公式アカウント | **0 円** | 無料プラン (月200通) に収まる見込み |
| Cloud Run (ホスティング) | **0 円** | 無料枠内 |
| Google スプレッドシート / Drive API | 0 円 | API 利用は無料 (クォータ内) |
| Google Workspace (共有ドライブ用) | 0 円 | 契約済みの既存プランを利用 (追加費用なし) |
| **合計** | **月 数円程度** | LINE が 200 通を超えた場合のみ +5,000 円 |

## 1. Gemini API（有料枠）

| モデル | 入力 (画像/テキスト) | 出力 |
| --- | --- | --- |
| gemini-2.5-flash (採用) | $0.30 / 100万トークン | $2.50 / 100万トークン |
| gemini-2.5-flash-lite | $0.10 / 100万トークン | $0.40 / 100万トークン |

**1回あたり**
- 画像: アップロード前に長辺1,800pxへ縮小 → 768px タイル 6枚 × 258 トークン ≈ 1,550 トークン
- プロンプト: 約 250 トークン → 入力合計 約 1,800 トークン = $0.00054
- 出力: 約 100 トークン (JSON のみ) = $0.00025
- **合計 約 $0.0008 ≒ 0.12 円 / 回**

※ 2.5 Flash は初期設定で「思考 (thinking)」が有効で、思考トークンも出力単価で課金されるため、`thinkingBudget: 0` で無効化しています（期限の読み取りに推論は不要。応答も速くなります）。

**月あたりの回数**

| 書類 | 年間件数 | 根拠 |
| --- | --- | --- |
| 免許証 | 約 8 件 | 30名 ÷ 有効期間 平均4年 |
| 検査証記録事項 | 約 13 件 | 25台 ÷ 車検周期 2年 |
| 自賠責 | 約 13 件 | 車検と同時更新 |
| 撮り直し・管理者アップロード | ×3 倍で見込む | |
| **合計** | **約 100 回 / 年 (月 10 回前後)** | → **月 1〜2 円** |

無料枠との違いは金額ではなくデータの扱いで、有料枠では入力データが Google のプロダクト改善に使われません。最低利用料はなく、請求先アカウントを紐付けるだけで有料枠になります。念のため Cloud Billing の予算アラート（例: 月 1,000 円）の設定を推奨します。

## 2. LINE 公式アカウント

| プラン | 月額 | 無料メッセージ | 追加送信 |
| --- | --- | --- | --- |
| コミュニケーション | 0 円 | 200 通 | 不可 |
| ライト | 5,000 円 | 5,000 通 | 不可 |
| スタンダード | 15,000 円 | 30,000 通 | 約 3 円/通 |

**月間の送信見込み**（GAS で同じドライバーへの通知を 1日1通にまとめています）

| 通知 | 月間 | 根拠 |
| --- | --- | --- |
| 期限 (免許・車検・自賠責) | 約 20 通 | 年34件 × 残り45/30/14/7/3/1/0日の区切り |
| オイル交換 | 約 25 通 | 月2,500〜3,000km走行で約2か月ごと。未対応なら3日おきに再送 |
| 走行距離の未報告 | 約 10 通 | |
| 管理者への即時通知 | 約 10 通 | 状態チェック異常・キズ報告 |
| 管理画面からの手動送信 | 約 10 通 | |
| **合計** | **約 75 通** | 無料の 200 通に収まる |

- 友だち登録時の返信 (Reply API) は送信数に数えられません
- 期限切れを放置するドライバーがいると毎日通知が届くため、1人あたり月30通増えます。200通を超えそうなら ライトプラン（5,000円）へ切り替えてください（無料プランは上限に達すると送信できなくなります）
